# Rift

> Catch risky database migrations before they reach production.

Rift is a CLI-based static analysis tool for SQL migrations.

## Current state

The repository now contains the first project scaffold for the v0.1 line:

- Maven build setup
- CLI command skeleton
- Domain model boundaries
- Dialect and risk abstractions
- Documentation structure under `docs/`
