# v0.1 Release Plan

## Release goal

Ship the first stable CLI foundation for analyzing risky SQL Server migrations locally and in CI.

## Release criteria

- Maven build exists and is reproducible.
- CLI entry point and commands are present.
- Core domain model is separated from parser implementation.
- Documentation exists for architecture, roadmap, and GitFlow.
- First rule set and risk reporting path are defined.

## Non-goals

- Full PostgreSQL support.
- Production-grade JSON reporting.
- Native binaries.
- Database execution or live connectivity.
